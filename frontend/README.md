# 🀄 国标麻将算番器

Chinese Official Mahjong Scoring Calculator

一个简洁、美观的国标麻将算番器，支持国标麻将全部81种番种的计算。

[English README](./README.en.md)

## ✨ 功能特点

- 📱 响应式设计，支持桌面和移动设备
- 🔍 支持番种搜索
- 🏷️ 按番数分类筛选
- 🎯 实时计算总番数
- 📖 内置番种说明
